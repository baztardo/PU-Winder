🎯 v1.7.1 - CONTINUOUS WINDING FIX!

============================================
THE BUG IN v1.7.0:
============================================

Ramp-up used PIO:
  ::spindle_step_pio_queue_cv(&spindle_step_pio, ...);  ✅

But continuous winding used OLD move_queue:
  move_queue->push_chunk(AXIS_SPINDLE, chunk);  ❌

Result: After ramp-up finished, the continuous 
winding tried to queue to move_queue, which did 
NOTHING because PIO was controlling the motor!

That's why it stopped after 1.5 seconds!

============================================
THE FIX IN v1.7.1:
============================================

Changed execute_winding() to use PIO:

BEFORE (v1.7.0):
  if (!move_queue->is_active(AXIS_SPINDLE) || ...) {
    move_queue->push_chunk(AXIS_SPINDLE, chunk);  ❌
  }

AFTER (v1.7.1):
  uint32_t fifo_level = pio_sm_get_tx_fifo_level(...);
  if (fifo_level < 2) {
    ::spindle_step_pio_queue_cv(&spindle_step_pio, ...);  ✅
  }

Now continuous winding uses the SAME PIO system 
as ramp-up!
