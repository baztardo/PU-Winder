### Your Mechanical Setup:
```
Stepper (40T) → Spindle (20T) = 2:1 reduction
Encoder (20T) → Spindle (20T) = 1:1 direct

Result: Stepper turns 2× for every spindle turn
        Encoder reads spindle speed directly
```

### What This Means:

## 🔍 What to Watch For:

### At High Speeds (>500 RPM spindle):
1. **Motor heating** - Touch motor, should be warm but not burning
2. **TMC2209 heating** - Driver should stay cool
3. **Encoder accuracy** - RPM should match target ±5%
4. **Step loss** - Position should keep climbing smoothly
5. **Vibration** - Motor should run smoothly, not grinding

### If Motor Stalls:
1. **Reduce speed** - Try 10% lower
2. **Increase current** - Edit `SPINDLE_CURRENT_MA` in config.h
3. **Check voltage** - 24V recommended for high speeds
4. **Reduce load** - Test without wire first
