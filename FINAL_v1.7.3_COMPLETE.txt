============================================
THE Z-INDEX DOUBLE-COUNT BUG:
============================================

OLD CODE (No Debouncing):
```cpp
bool z_now = gpio_get(ENCODER_Z_PIN);
if (!z_now && last_z) {
    z_pulse_detected = true;  // ← Any falling edge triggers!
}
```

Problem: If Z signal bounces/has noise, multiple triggers!

Z signal:  ‾‾‾\__/‾‾‾\_____/‾‾‾‾
                ↑    ↑
                1st  2nd trigger! ❌ DOUBLE COUNT!

Result:
- Layer changes too early
- Turn counting wrong
- Synchronization broken

============================================
THE FIX IN v1.7.3:
============================================

NEW CODE (With Spatial Debouncing):
```cpp
bool z_now = gpio_get(ENCODER_Z_PIN);
if (!z_now && last_z) {
    // Debounce: Only trigger if moved >90° since last Z
    int32_t delta = abs(position - z_debounce_position);
    if (delta > (ENCODER_CPR / 4)) {  // >1/4 revolution
        z_pulse_detected = true;
        z_debounce_position = position;  // Remember position
    }
}
```

How it works:
1. Detects falling edge
2. Checks: "Have we moved >90° since last Z trigger?"
3. If YES: Real Z-index! Trigger it.
4. If NO: Noise/bounce! Ignore it.

Since Z-index is physically at ONE position on the encoder,
it's IMPOSSIBLE to see it twice within 90° of rotation!
