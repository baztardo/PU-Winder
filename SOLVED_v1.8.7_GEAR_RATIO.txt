# ✅ v1.8.7 - GEAR RATIO FIXED!

## THE SMOKING GUN:

Your testing revealed:
```
Config  60 RPM → Hardware 120 RPM (2× too fast!)
Config 120 RPM → Hardware 240 RPM (2× too fast!)
```

**We had the gear ratio backwards!**

---

## THE MECHANICAL REALITY:

```
Stepper shaft: 40 teeth
Spindle shaft: 20 teeth

40T driving 20T = SPEED-UP ratio
1 stepper revolution → 2 spindle revolutions
Stepper is SLOWER than spindle (1:2 ratio)
```

---

## THE BUG:

We were doing:
```cpp
stepper_rpm = spindle_rpm × 2.0  ❌ WRONG!
```

So:
- Config 60 spindle
- Code calculated: 60 × 2 = 120 stepper
- Through gears: 120 stepper → 240 spindle ❌

**Result: 4× the configured speed!**

Wait, but you're only seeing 2×...

Actually:
- Config 60 spindle
- Code: 60 × 2 = 120 stepper RPM = 1600 sps
- Motor runs at 1600 sps
- Through 2:1 gears: Spindle at 120 RPM ✓

So we're getting 2× because we're commanding the stepper at 2× what we should!

---

## THE FIX (v1.8.7):

```cpp
#define SPINDLE_GEAR_RATIO 0.5f  // ✅ CORRECT!

stepper_rpm = spindle_rpm × 0.5
```

Now:
- Config 60 spindle
- Code: 60 × 0.5 = 30 stepper RPM = 400 sps
- Motor runs at 400 sps (30 RPM stepper)
- Through 2:1 gears: 30 × 2 = **60 RPM spindle** ✅
