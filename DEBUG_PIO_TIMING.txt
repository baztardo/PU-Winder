Commanded: 3200 sps (120 RPM spindle)
Encoder shows: 220 RPM spindle

## POSSIBLE CAUSES:

### 1. PIO Clock Divider Wrong?
```cpp
// spindle_step.pio line 43:

```

The PIO might not have a clock divider configured!

### 2. PIO Timing Loop Bug?
The PIO program might have incorrect cycle counting.

### 3. System Clock Not 125 MHz?
```cpp
cycles_from_sps() assumes:
uint32_t clk = clock_get_hz(clk_sys);  // Should be 125 MHz
```

Maybe system clock is different?
