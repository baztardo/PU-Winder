============================================
THE BUG:
============================================

Z-index detection had NO hysteresis or debouncing:

OLD CODE (v1.7.2):
  if (!z_now && last_z) {
    z_pulse_detected = true;  ← Triggers on EVERY falling edge!
  }

Problems:
1. Electrical noise → false triggers
2. Wide Z pulse → multiple detections  
3. Motor vibration at start → re-trigger
4. ISR runs 20,000 times/sec (every 50μs)
5. Z pulse is ~7ms wide = 140 ISR hits!

============================================
HOW DOUBLE-COUNTING HAPPENED:
============================================

Scenario 1 (Noise):
  T=0.00ms: Z falls → flag TRUE
  T=0.05ms: check_z_pulse() clears flag
  T=0.10ms: Z bounces HIGH (noise)
  T=0.15ms: Z falls again → flag TRUE AGAIN! ❌

Scenario 2 (Motor Start):
  Homing: Z detected at pos=1200
  Motor stops near Z-index
  Ramp-up: Motor vibrates
  Z triggers AGAIN! ❌

Result:
- Wrong turn count
- Premature layer changes
- Synchronization errors

============================================
THE FIX (v1.7.3):
============================================

Added **HYSTERESIS** - Z can only re-trigger after 
moving 90° (quarter revolution) away!

NEW CODE:
  // Track where Z was last detected
  z_trigger_position = position when Z fired
  
  // Re-arm only after moving > 90° away
  if (abs(position - z_trigger_position) > ENCODER_CPR/4) {
    z_armed = true;
  }
  
  // Only detect Z if armed
  if (z_armed && !z_now && last_z) {
    z_pulse_detected = true;
    z_trigger_position = position;
    z_armed = false;  ← Disarm immediately!
  }

Dead Zone: 360 counts = 90° = ENCODER_CPR/4

============================================
HOW IT PREVENTS DOUBLE-COUNT:
============================================

Timeline:
  pos=1200: Z detected, z_armed = FALSE
  pos=1201-1559: Z CANNOT trigger (disarmed!)
  pos=1560: Moved 90° away, z_armed = TRUE
  pos=2640 (next revolution): Z can trigger again ✅

Even if Z bounces or motor vibrates:
- Z is DISARMED for 90° of rotation
- Noise/bounce IGNORED
- Clean, single detection per revolution!
