# 🐛 v1.8.9 - TURN COUNTING BUG FIXED!

## THE BUG:

Your test: 100 turns target → **124 actual!** (+24% error!)

This is NOT mechanical tolerance - this is a COUNTING BUG!

---

## ROOT CAUSE:

**Double counting in `update_display()`!**

```cpp
// winding_controller.cpp line 561:
void WindingController::update_display() {
    const int32_t enc_counts = encoder->get_position();
    turns_completed = enc_counts / ENCODER_CPR;  // ❌ OVERRIDES!
    ...
}
```

**This OVERWRITES `turns_completed` which is managed by `sync_traverse_to_spindle()`!**

---

## HOW IT CAUSED +24% ERROR:

### Normal Flow (CORRECT):
```cpp
sync_traverse_to_spindle():
- Reads encoder delta since last sync
- Calculates new_turns from delta
- Updates turns_completed incrementally ✓
```

### Bug Flow (WRONG):
```cpp
update_display():
- Reads TOTAL encoder position
- Recalculates turns from absolute position
- OVERWRITES turns_completed! ❌

Result:
- sync_traverse_to_spindle() increments: +1
- update_display() recalculates from total: +1.24
- Net result: Counts 24% too high!
```

---

## THE FIX (v1.8.9):

**Removed the override line:**
```cpp
// OLD:
turns_completed = enc_counts / ENCODER_CPR;  // ❌

// NEW:
// Removed! turns_completed managed by sync only ✅
```

**Now `turns_completed` is ONLY updated by `sync_traverse_to_spindle()`!**
