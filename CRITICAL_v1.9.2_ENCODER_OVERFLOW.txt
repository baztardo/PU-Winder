# 🚨 v1.9.2 - ENCODER FIFO OVERFLOW FIX

## THE BUG (v1.9.1):

Motor ran smooth at 8000 sps (600 RPM stepper / 1200 RPM spindle)
**BUT ENCODER STOPPED COUNTING!** ❌

```
Ramp slice 24: 8000 sps ✓
Motor: Smooth, no stalls ✓  
Encoder: NO COUNTS ❌❌❌
```

---

## ROOT CAUSE:

**PIO sampling TOO FAST → FIFO overflow → Lost samples!**

### The Math:

At 1200 RPM spindle:
```
Expected encoder events: 28,800 counts/sec

OLD PIO sample rate:
- Clock: 125 MHz / 1 = 125 MHz  
- With in pins, 2: 125M / 2 = 62.5 MHz samples/sec!
- FIFO size: 8 words
- ISR drains: 16 samples every 50μs = 320,000/sec

Result: PIO generates 62.5 MILLION samples/sec!
        ISR drains 320,000 samples/sec
        FIFO overflows in microseconds! ❌
```

**The 8-word FIFO can't keep up!**

---

## THE FIX (v1.9.2):

### **1. Slow Down PIO Sampling**

```pioasm
OLD:
.wrap_target
    in pins, 2       ; Sample every 2 cycles = 62.5 MHz!
    push noblock
.wrap

NEW:
.wrap_target
    in pins, 2 [31]  ; Sample + wait 31 cycles = 32 total
    push noblock     ; Now samples at: 125M / 32 = 3.9 MHz
.wrap
```

**New sample rate: 3.9 MHz = 3,900,000 samples/sec**

### **2. Drain FIFO Faster**

```c
OLD: while (...samples_processed++ < 16)
NEW: while (...samples_processed++ < 32)  // Drain 2x per ISR tick!
```

---

## 📊 NEW PERFORMANCE:

At 1200 RPM spindle (8000 sps):
```
Encoder events: 28,800/sec
PIO samples: 3,900,000/sec (136x oversample) ✓

FIFO depth: 8 words

Max FIFO fill time: 8 / 3.9M = 2 microseconds
ISR drain time: Every 50 microseconds
Safety margin: 25x! ✓✓✓
```
