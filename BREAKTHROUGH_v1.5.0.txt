============================================
THE ROOT CAUSE:
============================================

150 RPM × 16x microstepping = 8000 steps/second
↓
Motor PHYSICALLY CAN'T turn that fast with 16x!
↓
Result: Stalling, huge negative positions, grinding tones

============================================
THE FIX - v1.5.0:
============================================

Use DIFFERENT microstepping for each axis:
- Spindle: 8x microstepping (can go faster!)
- Traverse: 16x microstepping (needs precision)

NEW MATH:
  300 RPM × 8x microstepping = 4000 steps/second ✅
  (Motor CAN handle this!)

============================================
WHY THIS WORKS:
============================================

16x microstepping:
- 200 steps/rev × 16 = 3200 steps/rev
- 300 RPM = 5 rps
- 5 rps × 3200 = 16000 sps (TOO FAST!)

8x microstepping:
- 200 steps/rev × 8 = 1600 steps/rev
- 300 RPM = 5 rps
- 5 rps × 1600 = 8000 sps (STILL TOO FAST!)

Wait... let me recalculate...

Actually at 300 RPM:
- 300/60 = 5 rps
- 5 × 1600 steps = 8000 sps

That's still hitting the limit! But the code now has a 3000 sps cap, so:
- Actual speed will be capped at 3000 sps
- 3000 sps / 1600 steps/rev = 1.875 rps = 112.5 RPM actual

So motor will run smoothly at 112.5 RPM (capped by 3000 sps limit).

To get full 300 RPM, you'd need to increase cap to:
- 300/60 × 1600 = 8000 sps

But start with 3000 sps and test if motor is smooth!
If smooth, we can gradually increase the cap.
